# Contributing to Namastack

Namastack Outbox and Once are independent, Apache 2.0 projects. Issues, pull requests and runnable examples live with each library. Website documentation is maintained here in the website repository.

- [Outbox contributing guide](https://github.com/namastack/namastack-outbox/blob/main/CONTRIBUTING.md)
- [Once contributing guide](https://github.com/namastack/namastack-once/blob/main/CONTRIBUTING.md)
- [Improve this website](https://github.com/namastack/namastack-website)
- [Join the Discord community](https://discord.gg/XNHP5Yhxy7)
