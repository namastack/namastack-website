# Support the work

Namastack Outbox and Namastack Once are independently developed, open-source libraries. Sponsorship supports maintenance, documentation, integrations, and long-term stability across both projects.

[Become a sponsor on GitHub →](https://github.com/sponsors/namastack)

You can also help by reporting reproducible issues, contributing examples, reviewing pull requests and sharing how you use the projects.
